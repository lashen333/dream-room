> **Transform any room in seconds with AI-powered interior design**

An AI-powered interior design platform that transforms room photos into stunning redesigns. Built with Next.js 14, TypeScript, and Tailwind CSS v4. Monetized through high-value affiliate commissions.

---

## ✨ Features

### 🎨 **AI-Powered Transformations**
- Upload any room photo
- Choose from 6 premium design styles
- Get stunning redesigns in seconds
- Powered by Stable Diffusion SDXL

### 📊 **Interactive Comparison**
- Smooth before/after slider
- Side-by-side view
- Shareable results
- HD downloads

### 💰 **Monetization Ready**
- "Shop This Look" affiliate products
- Amazon & Wayfair integration
- High-ticket furniture commissions ($50-$150)
- Premium subscription tier

## 🚀 Quick Start

```bash
# Install dependencies (already done)
npm install

# Add your Replicate API key to .env.local
REPLICATE_API_TOKEN=r8_your_token

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

See [SETUP.md](SETUP.md) for detailed instructions.
